BizForge 🚀

AI-powered Business Intelligence & Automation Platform

BizForge is a smart platform that helps businesses analyze data, automate workflows, and gain insights using AI-driven tools. It combines a modern frontend with powerful backend services for sentiment analysis, content generation, and business intelligence.

📊 AI-powered dashboard
💬 Sentiment analysis
🧠 Smart content generation
🔗 Backend API services
⚡ Fast React + Vite frontend

🚀 Getting Started
1️⃣ Clone the repository
git clone https://github.com/your-username/BizForge.git
cd BizForge
2️⃣ Setup Frontend
cd Frontend
npm install
npm run dev
3️⃣ Setup Backend
cd Backend
pip install -r requirements.txt
python main.py
🔑 Environment Variables

Create .env.local in frontend:

GEMINI_API_KEY=your_api_key_here

Create .env in backend:

API_KEY=your_api_key_here
📌 Usage
Start backend server
Start frontend server
Open browser at http://localhost:5173
Use dashboard for AI-powered insights
